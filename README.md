# Jastin Lamug — Portfolio v3

Minimal horizontal parallax portfolio built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features

- Horizontal scrolling panoramic canvas with parallax backgrounds
- Interactive project cards with image gallery modals
- High-resolution certificate viewer with keyboard navigation
- Live interactive screen archives of previous portfolio versions (v1 & v2)
- Terminal-style contact widget (contact.sh)
- Dark/light theme toggle with smooth circular reveal animation
- Responsive design optimized for desktop and mobile

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```

## Build for Production

```bash
npm run build
```

## Deploy to GitHub Pages

The built output in `dist/` can be deployed directly to GitHub Pages.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Motion (Framer Motion)
- Lucide React Icons
